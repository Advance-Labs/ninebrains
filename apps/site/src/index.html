LIVE · LANES

Every agent gets its own world.

Its own git worktree and branch, terminal, editor and browser. Four lanes to a tab, as many tabs as you want. They cannot touch each other's files, so nothing merges by accident. 

$ ls .ninebrains/worktrees
lane-1  lanes/a1e02c  claude
lane-2  lanes/9c7f41  codex
lane-3  lanes/2b81aa  claude
lane-4  lanes/f30d19  freebuff
4 lanes, 4 worktrees, 0 shared files

LIVE · THE BRAIN

One plan, handed out as it unblocks.

The Brain holds the work as a graph of jobs with dependencies, plus a mailbox the lanes can talk through. A job goes to whichever lane is idle, the moment everything it depends on is done. 

$ brain plan "add search to the docs site"
compiled 5 jobs, 3 dependency edges
job-1 index-content        ready → lane-2
job-2 search-ui            blocked on job-1
job-3 search-api           blocked on job-1
job-1 done, dispatching job-2 and job-3

LIVE · VERIFICATION GATES

No agent grades its own work.

When a lane says it is done, a second, independent run has to prove it: the tests, a screenshot check at three widths, a read-only reviewer that never sees the lane's worktree. A failed gate sends feedback back with the evidence, three times, then blocks the job and tells you. 

$ gate run job-2 --attempt 1
tests            FAIL  2 of 41
screenshots      pass  390 / 768 / 1440
reviewer         pass  read-only checkout
→ feedback sent to lane-2, attempt 2 of 3
$ gate run job-2 --attempt 2
tests            PASS  41 of 41

LIVE · PLANNER

Draw the plan. Run the plan.

Jobs are nodes, dependencies are edges. Run plan compiles the canvas into Brain jobs, idempotently, and refuses a graph with a cycle in it. 

$ planner compile docs-search.plan
3 nodes, 2 edges, 1 module
checking for cycles… none found
compiled → 3 jobs queued (idempotent)

LIVE · PACKS

Bundles for the work, off until you need them.

Per-project bundles of lane roles, skills, MCP servers and gates, for coding, SEO and research. Every pack is off until you turn it on. 

$ packs list --project ninebrains
coding    on   builder, reviewer roles
seo       off  needs AEO_MCP_BASE_URL
research  off  citation-check gate

LIVE · FREEBUFF FALLBACK

A usage limit does not end the lane.

When Claude Code or Codex hits its usage limit mid-task, the lane offers to continue in Freebuff, handed off with a note on what was done and what is left, so the work keeps moving. 

$ lane-3 status
claude: usage limit reached
continue in freebuff? [Y/n] y
handing off: git status, git diff, task notes
lane-3 resumed with freebuff
Unsigned build: why, and how to verify

v0.1 builds are not code-signed, so macOS Gatekeeper and Windows SmartScreen will warn you before you open one. The installer downloads the release's SHA256SUMS file and checks the artifact before it touches your disk; a mismatch aborts. That proves you have the exact bytes the release published. It does not prove who built them, so only ever install from github.com/Advance-Labs/ninebrains or this site.

Full steps, including gh attestation verify and how to open an unsigned build by hand, are in Verify a download.
